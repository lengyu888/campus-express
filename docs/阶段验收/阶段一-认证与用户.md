# 阶段一验收：认证与用户管理

> 阶段目标：打通 Docker 基础设施、FastAPI 后端、Vue 前端与 MySQL，完成登录鉴权与用户管理。
> 状态：已验收并提交（commit `3236e37`）。

## 一、本阶段完成内容

**基础设施**

- `deploy/docker-compose.infra.yml`：仅启动 MySQL 8.0 与 Redis 7，供本地开发使用
- `deploy/docker-compose.yml`：前端 + 后端 + MySQL + Redis 一键启动
- MySQL 使用官方 `mysql:8.0` 镜像，数据卷持久化，字符集 utf8mb4
- `deploy/mysql/init/01-init.sql`：初始化字符集与时区

**后端（FastAPI）**

- 统一响应结构 `{code, message, data, request_id}` 与全局异常处理
- JWT 双令牌（访问 2 小时 / 刷新 7 天），注销写入 Redis 黑名单
- 登录失败 5 次锁定 15 分钟（Redis 计数）
- 密码 bcrypt 加密；手机号唯一；角色 RBAC
- 接口：登录、刷新、注销、当前用户、改密、注册；用户列表、新增、详情、修改、启停
- Alembic 迁移 `0001_create_users`；`app.seed` 初始化演示账号
- `/health` 与 `/api/v1/health` 健康检查

**前端（Vue 3 · iOS 风格）**

- 设计语言：iOS 浅色体系（#F2F2F7 背景、系统蓝 #007AFF）、毛玻璃侧边栏与卡片、22–32px 大圆角、细发丝分隔线
- 登录页：渐变光斑背景、居中磨砂玻璃卡片、演示账号点选填充
- 主框架：悬浮毛玻璃侧边栏、白色滑块式菜单指示器（弹性位移动画）、顶部状态胶囊
- 工作台：渐变主卡片、数字滚动统计、阶段时间线、验收指引
- 用户管理：搜索 + iOS 分段控件筛选、头像列表、角色胶囊标签、iOS 绿色开关
- 个人中心：渐变头像环、分组信息列表、修改密码
- 动效：路由淡入上移、卡片错峰入场、悬停抬升、按钮按压缩放、弹窗弹性出现
- 路由守卫、401 自动刷新令牌、403/404 页面

## 二、启动方式

### 方式 A：本地开发（推荐）

前置：Docker Desktop 已启动，Node 20+，Python 3.12+。

```bash
# 1. 启动数据库与缓存
cd C:/Users/28482/Desktop/Campus_Express
cp deploy/.env.example deploy/.env          # 首次
docker compose -f deploy/docker-compose.infra.yml up -d

# 2. 后端
cd backend
cp .env.example .env                        # 首次
python -m venv .venv                        # 首次
./.venv/Scripts/pip install -r requirements.txt
./.venv/Scripts/alembic upgrade head
./.venv/Scripts/python -m app.seed
./.venv/Scripts/uvicorn app.main:app --reload --port 8000

# 3. 前端（新终端）
cd frontend
npm install                                 # 首次
npm run dev
```

访问：http://localhost:5173  
接口文档：http://localhost:8000/docs

### 方式 B：Docker 一键启动

```bash
cd C:/Users/28482/Desktop/Campus_Express
cp deploy/.env.example deploy/.env          # 首次
docker compose -f deploy/docker-compose.yml up -d --build
```

访问：http://localhost （前端 Nginx 已代理 `/api` 到后端）

停止：`docker compose -f deploy/docker-compose.yml down`  
重置数据：`docker compose -f deploy/docker-compose.yml down -v`

## 七、动效升级（V1.1）

### 7.1 动效分级

| 档位 | 触发条件 | 表现 |
| --- | --- | --- |
| 完整 full | 默认；CPU > 4 核、内存 > 4 GB 且系统未开启减少动态 | 全部动效：视差、3D 倾斜、模糊入场、光晕跟随 |
| 低配 low | CPU ≤ 4 核或内存 ≤ 4 GB；或启动 1.4 秒内平均帧率 < 45 | 关闭模糊、3D 倾斜、视差与光斑动画，只保留位移与淡入 |
| 精简 reduced | 系统 `prefers-reduced-motion: reduce`，或用户手动切换 | 只保留必要的颜色/透明度反馈，禁用位移、模糊与循环动画 |

### 7.2 开关位置

- 顶栏魔棒图标：一键在「完整 / 精简」之间切换，状态持久化到 localStorage
- 个人中心 →「体验与动效」：跟随系统 / 完整动效 / 精简动效，并显示当前档位

### 7.3 已实现的动效场景

| 场景 | 具体效果 |
| --- | --- |
| 登录转场 | 登录成功后按钮变绿并显示勾选，卡片放大、上移、模糊淡出后进入工作台 |
| 路由转场 | 按菜单顺序判断方向，前进右滑入、后退左滑入；顶部 2.5px 渐变进度条 |
| 导航 | 侧边栏白色指示块弹性滑动，图标与文字颜色过渡，按压缩放 |
| 数据卡片 | 统计数字缓动滚动；主卡片随鼠标视差、滚动视差；卡片 3D 倾斜与聚光跟随 |
| 滚动联动 | 元素进入视口时错峰渐显（IntersectionObserver）；滚动超过 110px 出现毛玻璃回顶按钮 |
| 列表 | 首次加载骨架屏微光；表格行错峰入场；启停账号整行绿/灰闪烁反馈 |
| 表单 | 校验失败弹窗抖动；按钮按压回弹；弹窗弹性缩放 + 遮罩模糊 |
| 状态反馈 | 改密成功按钮变绿显示「已保存」；健康状态点脉冲；动效档位指示灯 |

### 7.4 性能与可访问性

- 动画仅使用 `transform` / `opacity`，滚动与指针事件用 `requestAnimationFrame` 节流
- 进入视口后立即 `unobserve`，动画结束释放 `will-change`
- 启动时采样帧率，低于 45fps 自动降级为 low，不阻塞主线程
- 全局 `:focus-visible` 焦点环、图标按钮 `aria-label`、动效开关 `aria-pressed`
- 正文次级文字对比度提升至约 4.8:1，满足 WCAG AA 小字号要求
